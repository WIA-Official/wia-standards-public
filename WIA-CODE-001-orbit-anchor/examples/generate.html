통째 config 아님 — 좌표+신뢰앵커. 스캔하면 에이전트가 검증된 연결을 맺음.
날짜는 "YYYY-MM-DD HH:MM"(24시간) 형식으로.
클수록 더 많은 데이터 (SSH 키·긴 설정은 L 권장). 스캔은 더 가까이/크게.
