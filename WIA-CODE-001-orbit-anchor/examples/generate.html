BIP-21 표준 (bitcoin:주소?amount=…). 금액은 BTC 단위 소수로 적은 그대로 들어갑니다.
EIP-681 표준 (ethereum:주소@체인?value=wei). 적어 넣은 ETH는 wei 정수로 정확히 변환됩니다 (0.001 ETH → 1000000000000000).
⚠️ 주소는 붙여넣은 뒤 반드시 눈으로 대조하세요. 한 글자만 어긋나도 되돌릴 수 없습니다. 코인과 주소 체계가 서로 맞는지도 확인하세요.
⚠️ 유럽/SEPA 계좌이체 전용이고 통화는 EUR만 됩니다 — 표준이 그렇게 못박혀 있어서 원화(KRW)나 국내 계좌이체에는 쓸 수 없습니다. 금액은 소수점 둘째 자리까지만 반영됩니다. 버전 002라 BIC는 비워도 됩니다.
쓰는 곳: 이미 쓰고 있는 2단계 인증을 새 폰이나 다른 인증 앱으로 옮길 때. 기존 비밀키로 코드를 만들어 새 기기에서 스캔하면 그대로 이어집니다.
⚠️ 이 코드는 계정 열쇠 그 자체입니다. 스캔하는 사람은 누구나 당신의 인증번호를 만들어낼 수 있어요 — 화면 캡처·공유·인쇄물 방치 금지. 옮긴 뒤에는 지우세요.

사내 교환기 내선·회의실 번호를 문 앞에 붙여두는 용도. 이미 sip:가 붙은 주소를 붙여넣으면 그대로 씁니다.
키 서버 없이 공개키를 직접 건네는 방법. 공개키라서 널리 뿌려도 안전합니다(비밀키는 절대 넣지 마세요). 붙여넣은 그대로 담기며 한 글자도 변형하지 않습니다 — 길어서 격자 L이 필요할 수 있어요.
서버 담당자에게 내 공개키를 건네는 용도 — 받은 쪽은 스캔해서 그대로 authorized_keys에 붙이면 끝. 위쪽 🔑 SSH 타입은 반대로 "접속할 서버 정보"라 서로 다릅니다.
